DECYZJA PROJEKTOWA — DLACZEGO NIE NASŁUCH NA 'submit'
--------------------------------------------------------------------------------
Formularz robi klasyczny POST i przeładowanie. Konwersja odpalona na zdarzeniu
'submit' ściga się z nawigacją: przeglądarka może przerwać żądanie do Google,
zanim wyjdzie. Część zgłoszeń przepadnie, w dodatku niemierzalnie.

Dlatego konwersja formularza siedzi na stronie podziękowania, nie na submit.
Strona podziękowania wyświetla się tylko po realnym przejściu przez wyslij.php,
więc mierzy sukces, a nie samo kliknięcie przycisku.

UWAGA — wyslij.php przekierowuje na podziekowanie.html także w liniach 12 i 17,
czyli po odrzuceniu bota. Bez zmiany w PHP boty będą zliczane jako konwersje.
Poprawka opisana na końcu, w sekcji ZALECANA ZMIANA W wyslij.php.

<!-- === DEWAX: konwersje Google Ads === -->
<script async src="https://www.googletagmanager.com/gtag/js?id=AW-XXXXXXXXX"></script>
<script>
window.dataLayer = window.dataLayer || [];
function gtag(){dataLayer.push(arguments);}
gtag('js', new Date());
gtag('config', 'AW-XXXXXXXXX');

(function(){
  'use strict';

  var wyslane = {};
  function konwersja(etykieta, wartosc, klucz){
    if (klucz && wyslane[klucz]) return;
    if (klucz) wyslane[klucz] = true;
    gtag('event', 'conversion', {
      send_to: etykieta,
      value: wartosc || 0,
      currency: 'PLN'
    });
  }

  // ---- b) kliknięcie w telefon -------------------------------------------
  // delegacja na dokumencie: łapie wszystkie 5 wystąpień naraz
  document.addEventListener('click', function(e){
    var a = e.target.closest ? e.target.closest('a[href^="tel:"]') : null;
    if (!a) return;
    konwersja('AW-XXXXXXXXX/ETYKIETA_TELEFON', 0, 'telefon');
  }, true);

  // ---- c) ukończenie kalkulatora -----------------------------------------
  window.dewaxKalkulatorUkonczony = function(dane){
    konwersja('AW-XXXXXXXXX/ETYKIETA_KALKULATOR',
              (dane && dane.wartosc) || 0,
              'kalkulator');
  };
})();
</script>
<!-- === koniec: konwersje Google Ads === -->

GDZIE WPIĄĆ PUNKT (c) — DOKŁADNE MIEJSCE
================================================================================

Kalkulator już wysyła zdarzenie w momencie pokazania wyniku. Nie trzeba szukać
„momentu ukończenia" — jest wskazany w kodzie.

index.html, linie 1037-1038, koniec funkcji policz():

    if(window.dataLayer)dataLayer.push({event:'dobor_result',moc_kw:+moc.toFixed(1),
      model:pompa.id,metry:metry,otwory:otwory,cena_od:Math.round(sumaMin),cena_do:Math.round(sumaMax)});

Dopisz JEDNĄ linię bezpośrednio pod tym pushem, przed zamykającym }:

    if(window.dewaxKalkulatorUkonczony)
      window.dewaxKalkulatorUkonczony({wartosc: Math.round(sumaMin)});

Efekt końcowy tego fragmentu:

    if(window.dataLayer)dataLayer.push({event:'dobor_result',moc_kw:+moc.toFixed(1),
      model:pompa.id,metry:metry,otwory:otwory,cena_od:Math.round(sumaMin),cena_do:Math.round(sumaMax)});
    if(window.dewaxKalkulatorUkonczony)
      window.dewaxKalkulatorUkonczony({wartosc: Math.round(sumaMin)});
  }

Dlaczego akurat tu, a nie przy ruchu suwakiem:
  * policz() kończy krok 4 kreatora, czyli pokazanie wyniku — dokładnie to,
    o co chodzi w punkcie (c)
  * nie jest wywoływane przy starcie strony, więc konwersja nie odpali się
    komuś, kto tylko wszedł
  * gdy ktoś cofnie się i przeliczy drugi raz, klucz 'kalkulator' w bloku A
    zatrzyma dublet

Wartość konwersji to dolna granica widełek (cenaOd), czyli kwota inwestycji,
a nie marża ani wartość leada. Jeśli chcesz optymalizować pod realną wartość,
przemnóż to własnym współczynnikiem, zanim wyślesz.

Alternatywa bez dotykania index.html: zamiast dopisywać linię, nasłuchuj
istniejącego zdarzenia. Wymaga GTM, którego na stronie nie ma, więc przy
obecnym stanie prostsza jest jedna linia wyżej.

ZALECANA ZMIANA W wyslij.php — ODCIĘCIE BOTÓW OD KONWERSJI
================================================================================

Bez niej każdy złapany bot zaliczy się jako zgłoszenie i zafałszuje Ads.

W wyslij.php linia 78 (przekierowanie po SUKCESIE) zmień na:

    header('Location: podziekowanie.html?ok=1');

Linii 12 i 17 (bot i zbyt szybkie wysłanie) NIE ruszaj — mają zostać bez ?ok=1.

Następnie w BLOKU B zamień samo wywołanie gtag na warunkowe:

    if (location.search.indexOf('ok=1') !== -1) {
      gtag('event', 'conversion', {
        send_to: 'AW-XXXXXXXXX/ETYKIETA_FORMULARZ',
        value: 0,
        currency: 'PLN'
      });
    }
